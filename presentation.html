Smart Muscle Condition Detection Using EMG and Posture Analysis

This project is a smart gym assistant that combines real-time exercise posture analysis, EMG muscle signal monitoring, workout timing, set and rep tracking, performance recommendations, and doctor lookup in one dashboard.

Core idea: help users perform exercises more safely and more effectively by monitoring movement form and muscle activity during squats and curls.
Frontend Dashboard Python Posture Engine ESP32 Bluetooth Serial EMG Recommendations

Slide 2

Problem Statement

Common gym problems

  • Users perform squats and curls with poor posture.
  • Muscle fatigue and imbalance are hard to observe visually.
  • Beginners do not know when to rest, when to stop, or how to improve.
  • Most people do not get immediate, personalized exercise feedback.

Our solution

  • Track body posture using Python MediaPipe pose analysis.
  • Read EMG data from ESP32 through Bluetooth serial.
  • Show live reps, posture score, raw EMG graphs, rest timers, and recommendations.
  • Provide medical support links when needed.

Slide 5

Posture Analysis Module

Technology used

  • Python
  • OpenCV
  • MediaPipe Pose Landmarker

How it works

  • Camera feed is processed in Python.
  • Body landmarks are detected frame by frame.
  • Joint angles are calculated for squats and curls.
  • Reps are counted automatically from angle thresholds.
Example: in squats, the system analyzes hip and knee angles. In curls, it analyzes elbow angles to detect the lifting and lowering phases.

The dashboard shows the processed posture feed coming from the Python backend so the user can visually confirm their form.

Slide 6

Muscle Analysis Module

Data source

  • ESP32 connected over Bluetooth serial
  • Windows assigns a COM port
  • Python serial bridge reads incoming EMG values

Incoming ESP32 format

  • raw1,envelope1,raw2,envelope2
  • The current graph plots only raw1 and raw2
  • Negative and positive values are displayed around a center line

Raw 1

Muscle channel 1 live signal

Raw 2

Muscle channel 2 live signal

Imbalance

Difference between both channels

Fatigue

Estimated from live signal strength over time

Slide 7

Combined Mode and Recommendations

Combined mode

  • Posture and muscle panels appear together
  • User monitors form and muscle behavior in one screen
  • Useful for comparing correct posture with EMG changes

Recommendations provided

  • Improve squat depth or chest position
  • Reduce momentum during curls
  • Take more rest if fatigue rises
  • Correct left-right muscle imbalance
At the end of the session, the system shows a performance summary based on reps completed, posture quality, and EMG behavior.
